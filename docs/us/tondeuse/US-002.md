## User story

En tant qu'opérateur, je veux qu'une tondeuse ne puisse jamais entrer sur une case occupée par une autre tondeuse, qu'elle ait déjà terminé ou pas encore démarré, afin que deux tondeuses ne se retrouvent jamais sur la même case.

## Incrément de valeur

Plusieurs tondeuses partagent la pelouse sans collision : une case occupée bloque un `F` comme un bord de pelouse.

## Critères d'acceptance

- [ ] CA-1 : une tondeuse arrêtée occupe sa case finale, qui bloque les tondeuses suivantes comme un bord. Exemple : pelouse `5 5`, tondeuse 1 `1 1 N` / `L`, tondeuse 2 `0 1 E` / `FL` → sortie `1 1 W\n0 1 N\n`. *(réf. spec : RM-15, RM-08 volet occupation)*
- [ ] CA-2 : une tondeuse pas encore exécutée occupe sa case de départ, qui bloque les tondeuses précédentes. Exemple : pelouse `5 5`, tondeuse 1 `0 0 E` / `FF`, tondeuse 2 `2 0 N` / `L` → sortie `1 0 E\n2 0 W\n`. *(réf. spec : RM-25)*
- [ ] CA-3 : quand une tondeuse démarre, sa propre case de départ ne la bloque pas : elle peut la quitter puis y revenir. Par exemple, `0 0 N` avec la séquence `FRRF` termine en `0 0 S`. *(déduit de RM-15 et RM-25)*
- [ ] CA-4 : un `F` bloqué par une case occupée n'est pas une erreur : la tondeuse garde sa position et son orientation, puis passe à l'instruction suivante. *(réf. spec : RM-08)*
- [ ] CA-5 : l'exemple de référence donne toujours `1 3 N\n5 1 E\n` avec la gestion de l'occupation active. *(réf. spec : RM-12, O-2)*
- [ ] CA-6 : sur une pelouse aux bornes maximales (`40075016 40075016`) avec quelques tondeuses, la simulation se termine sans erreur mémoire. Ce test garantit que la pelouse n'est jamais matérialisée. *(réf. spec : RM-24)*

## Contraintes techniques (héritées du .tech.md)

- L'occupation est une grille creuse : un `HashSet<Position>` initialisé avec toutes les positions de départ. Au démarrage d'une tondeuse, sa case est retirée de l'ensemble ; à son arrêt, sa case finale y est ajoutée. Pas de matrice `boolean[][]`, et pas de parcours de la liste des tondeuses à chaque `F`.
- Une case est bloquante si elle est hors bornes ou présente dans l'ensemble. Cette vérification se fait en O(1) moyen.
- La grille d'occupation et la simulation sont dans `domain`.
